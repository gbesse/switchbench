Ajouter les traductions à `src/i18n.js` et préserver les noms des placeholders. Conserver les noms de produits, identifiants de code et données utilisateur sans traduction automatique. Mettre à jour les trois README pour les passages modifiés. Vérifier `npm test`, `npm run test:browser` et `npm run format:check`. Les tests navigateur doivent couvrir les trois langues. Distinguer les simulations des mesures physiques et documenter les hypothèses du modèle.
